# Troubleshooting

- **Disc not found:** put your image in `discs/` or set `TSFP_DISC`.
- **XBE extraction failed:** use an original, readable Xbox game ISO; the launcher extracts `default.xbe` before lifting.
- **Lift failed:** confirm the image is readable and is the original game disc.
- **Tool missing:** install the tools listed in the quick start and retry.
- **Build out of memory:** close other build jobs and retry.
- **No display:** visible output needs a supported Vulkan display.

Never send or commit disc images, extracted game files, or game screenshots.
